# 互換環境の廃止と日本語入力の既定化

状態: ユーザー了承済み。実装・ビルド確認完了。

## 目的

利用者が日本語入力版から試せるように、既定環境をcores3-text-inputにする。互換用m5stack-cores3とm5stack-cores3-pieを削除し、01〜05の5環境に整理する。

## 対象・主な変更

- platformio.ini: default_envsをcores3-text-inputへ変更。互換2環境のセクションと説明コメントを削除。
- README.md: 冒頭、環境一覧、標準ビルド・書き込み例、再実行コマンドの説明を既定の日本語入力版に合わせる。互換環境への案内を削除し、固定入力版はcores3-streaming等を明示して選ぶ説明にする。
- 本ステアリングへ検証結果を記録する。

## 影響・設計上の注意

- 環境指定なしのpio runは05をビルドするため、model/k1-dict-44000-2mb.binが必要になる。READMEの最初のビルド手順で辞書の配置先・取得手順への案内を示す。
- 05はReady後に日本語文章または/rを改行付きで送る。固定入力版のrとは区別する。
- 削除する環境名を指定したコマンドは使えなくなる。W8A32の蓄積再生専用環境は廃止され、既存のW8A32推論環境は残る。
- examples01〜05のソース・ライブラリ・モデル・辞書・パーティションは変更しない。過去のステアリングやバックアップは履歴資料として残す。

## 確認方法

- PlatformIOの設定解析で環境が5つ、既定がcores3-text-inputであることを確認する。
- 環境指定なしのpio runでcores3-text-inputが選ばれてビルドできることを確認する。取得済み依存を使用する。
- 現行の利用案内に廃止環境や旧既定の説明が残らないことを確認する。
- git diff --checkを行い、ソースやモデルに変更がないことを確認する。
